\begin{abstract}
We ask how much exponentially growing history a proper metric host can carry
under a linear radial budget, when the code is required to preserve
successively more of the source's own structure. The kernel is a packing
converse, $\beta \le c\,\hpack$. The distinctive claim is that the resulting
capacity is not a single number: imposing a quasi-isometry obligation on the
code can strictly reduce what is representable, and we exhibit a proper metric
host and an explicit source where it does---and, over the family of sources
whose own metric has uniformly bounded balls (bounded valence), at the level of
capacities: relational capacity $0$ against block capacity $\log 2$. The
converse, the block endpoint, the separation, the capacity-level separation,
and the host's properness and packing entropy are formally verified in Lean~4
against Mathlib. This note
states the definitions and results precisely, marks exactly which statements
are machine-checked and which are not, and isolates the questions we believe
are open.
\end{abstract}

\section{Setup}

Throughout, $(M,d)$ is a metric space with basepoint $o$, and $\varepsilon>0$ is
a fixed resolution. $S$ is a set of \emph{histories}.

\begin{definition}[Source]
A \emph{source} is a map $\sigma:\mathbb{N}\to\mathcal{P}_{\mathrm{fin}}(S)$
with each census $\sigma(R)$ finite and nonempty. It \emph{has growth} $\beta$
if $\log|\sigma(R)|/R \to \beta$.
\end{definition}

The source owns its filtration. This matters: bundling the census into the code
makes ``can this host carry \emph{this} source?'' unstatable, and conflates it
with ``what rates does this host support?''

\begin{definition}[Code]
A \emph{code} is a pair $\kappa=(\mathrm{addr},r)$ with
$\mathrm{addr}:\mathbb{N}\to S\to M$ and $r:\mathbb{N}\to\mathbb{R}$.
Write $\kappa_R(\sigma) = \mathrm{addr}(R)\bigl(\sigma(R)\bigr)\subseteq M$.
\end{definition}

\begin{definition}[Obligations]
An \emph{obligation} is a predicate on pairs $(\sigma,\kappa)$.
\begin{itemize}
\item \textbf{Base} $=$ \textbf{Faithful} $\wedge$ \textbf{Radial}:
  $\mathrm{addr}(R)$ is injective on $\sigma(R)$, its image is
  $\varepsilon$-separated, and $\kappa_R(\sigma)\subseteq \bar B(o,r(R))$.
\item \textbf{Relational} at lawful distortion $q=(D,K)$, $D\ge 1$, $K\ge 0$
  (requires a metric on $S$): for all $R$ and all $u,v\in\sigma(R)$,
  \[
    D^{-1} d_S(u,v) - K \;\le\; d\bigl(\mathrm{addr}(R)u,\mathrm{addr}(R)v\bigr)
    \;\le\; D\, d_S(u,v) + K .
  \]
\end{itemize}
\end{definition}

Base feasibility is not optional. The radial budget $r$ is a free field of the
code, unrelated \emph{a priori} to where $\mathrm{addr}$ places anything; without
Base, a code mapping every history to a single point and declaring
$r(R)=cR$ satisfies every rate condition, and a one-point host reports a
positive rate. (This degenerate witness is included in the formalization
precisely so the omission cannot recur.)

\begin{definition}[Representability and capacity]
$\sigma$ is \emph{$\mathcal{A}$-representable at radial rate $c$}, written
$\mathrm{Rep}_{\mathcal A}(\sigma,c)$, if there is a code $\kappa$ with
$\mathrm{Base}(\sigma,\kappa)$, $\mathcal A(\sigma,\kappa)$,
$r(R)\to\infty$, and $r(R)/R\to c$.

For a declared family $\mathfrak{S}$ of sources,
\begin{align*}
  \Rates_{\mathfrak S,\mathcal A}(c)
  &\;=\;\bigl\{\beta : \exists\,\sigma\in\mathfrak S,\ \sigma \text{ has growth }
  \beta \text{ and } \mathrm{Rep}_{\mathcal A}(\sigma,c)\bigr\},\\
  \Capy_{\mathfrak S,\mathcal A}(c) &\;=\;\sup \Rates_{\mathfrak S,\mathcal A}(c).
\end{align*}
\end{definition}

Capacity is a set before it is a number: boundedness is a theorem
(Theorem~\ref{thm:converse}), and the supremum is taken only afterwards.

\begin{definition}[ULF]
$\sigma$ is \emph{uniformly locally finite} if
$\exists K>0$ with $|\sigma(R+1)| \le K\,|\sigma(R)|$ for all $R$.
\end{definition}

This is a finite-generation-rate condition on the source's clock (Lean
\texttt{Source.ULF}); it is \emph{not} a restriction on the universal
converse, which holds for arbitrary sources including bursty ones. A second,
independent finiteness condition concerns the source's own metric.

\begin{definition}[Metric-ULF]
$\sigma$ is \emph{metric-ULF} (Lean \texttt{Source.MetricULF}) if there is
$f:\mathbb N\to\mathbb N$ with
$|\{v\in\sigma(R): d_S(u,v)\le t\}|\le f(t)$ for all $R$, all $u\in\sigma(R)$
and all $t$: uniformly bounded balls in $d_S$, the standard meaning of a
uniformly locally finite metric space, and bounded valence in the tree case.
\end{definition}

The binary tree is both clock-ULF ($K=2$) and metric-ULF ($f(t)=2^t$); a star
with $2^i$ leaves is clock-ULF and not metric-ULF. The canonical class for
relational statements is the metric-ULF clocked tree, and the distinction is
exactly what separates Theorem~\ref{thm:sepcap} from Question~\ref{q:sep}.

\section{The three stacked facts}

\begin{theorem}[Packing converse; Lean]\label{thm:converse}
Let $M$ be proper and $\varepsilon>0$, and suppose the packing growth
converges:
\[
  \frac{\log P\bigl(\bar B(o,\rho),\varepsilon\bigr)}{\rho}
  \;\longrightarrow\; \hpack \qquad (\rho\to\infty).
\]
Then for every family $\mathfrak S$ and every obligation $\mathcal A$,
\[
  \beta \in \Rates_{\mathfrak S,\mathcal A}(c)
  \;\Longrightarrow\;
  \beta \le c\,\hpack .
\]
\end{theorem}

The finite-depth form, which is what a measurement computes, is
$\log|\sigma(R)|/r(R) \le \log P(\bar B(o,r(R)),\varepsilon)/r(R)$; the
asymptotic statement discards an additive constant.

\begin{theorem}[Obligation monotonicity; Lean]
If $\mathcal A \Rightarrow \mathcal B$ pointwise then
$\Rates_{\mathfrak S,\mathcal A}(c) \subseteq \Rates_{\mathfrak S,\mathcal B}(c)$.
Likewise $\mathfrak S\subseteq\mathfrak T$ gives
$\Rates_{\mathfrak S,\mathcal A}\subseteq\Rates_{\mathfrak T,\mathcal A}$.
\end{theorem}

\begin{theorem}[Block endpoint, constructive; Lean]\label{thm:block}
Let $M$ be proper, $\varepsilon>0$, $c>0$, and
$\log P(\bar B(o,\rho),\varepsilon)/\rho \to \hpack$. Taking
$\sigma(R)$ to be an optimal $\varepsilon$-packing of $\bar B(o,cR)$ and
$\mathrm{addr}(R)=\mathrm{id}$ yields
$c\,\hpack \in \Rates_{\mathrm{all},\,\mathrm{noExtra}}(c)$, hence
$\Capy_{\mathrm{all},\,\mathrm{noExtra}}(c) = c\,\hpack$.
\end{theorem}

\begin{remark}[Depthwise recoding]
Theorem~\ref{thm:block} achieves the endpoint with codebooks chosen
independently at each radius: every address may be rewritten at every depth.
It is \emph{not} a nested, persistent, or successively refinable code, and the
Shannon analogy should be read with that qualification. Persistent
achievability is open.
\end{remark}

Together:
\[
  \beta \;\le\; \Capy_{\mathfrak S,\mathcal A}(c) \;\le\;
  \Capy_{\mathfrak S,\mathrm{noExtra}}(c) \;=\; c\,\hpack .
\]
The content of the theory is entirely in whether the middle inequality can be
strict.

\begin{theorem}[The persistent rung; Lean]\label{thm:persistent}
Let $M$ be proper, $\varepsilon>0$, $c>0$, with convergent packing rates at
resolutions $\varepsilon$ and $2\varepsilon$. Over retentive sources
($\sigma(R)\subseteq\sigma(R{+}1)$, \texttt{Source.Retentive}) under the
obligation that an assigned address never moves (\texttt{Stable}~$m$, any
$m\ge0$),
\[
  c\,\hpack(2\varepsilon)\;\le\;\Capy_{\mathrm{pers}}(\varepsilon)
  \;\le\;\Capy_{\mathrm{noExtra}}(\varepsilon)\;=\;c\,\hpack(\varepsilon),
\]
and if the balls of radius $2\varepsilon$ have uniformly bounded packing number
at resolution $\varepsilon$, both inequalities are equalities: the block rate
is achieved by one nested family of addresses that never move
(\texttt{Persistent.lean}: \texttt{achievable\_\allowbreak{}stable\_\allowbreak{}persistent},
\texttt{capacity\_\allowbreak{}stable\_\allowbreak{}between},
\texttt{capacity\_\allowbreak{}stable\_\allowbreak{}eq\_\allowbreak{}packing\_\allowbreak{}of\_\allowbreak{}boundedGeometry}).
\end{theorem}

The construction is a nested family of separated sets, each extended to a
cover of the next ball by a maximal separated subset of the far region, then
thinned to a nested census of size exactly the packing count at $2\varepsilon$;
the identity map is the code. The equality clause is the scale-invariance
theorem of \texttt{CoarseConverse}. Nesting therefore costs at most the gap
between two scales of packing entropy; the ladder's price, where there is one,
is paid at the relational rung.

\section{The separation}

\begin{definition}[Balloon]
Let $B$ have points $\mathsf{hub}(i)$, $i\in\mathbb{N}$, and
$\mathsf{leaf}(i,a)$, $a \in \mathbb{Z}/2^i$, with
\[
 d(\mathsf{hub}\,i,\mathsf{hub}\,j)=|i-j|,\quad
 d(\mathsf{hub}\,i,\mathsf{leaf}(j,b))=|i-j|+1,
\]
\[
 d(\mathsf{leaf}(i,a),\mathsf{leaf}(j,b))=
 \begin{cases} 0 & i=j,\ a=b\\ 2 & i=j,\ a\ne b\\ |i-j|+2 & i\ne j.\end{cases}
\]
\end{definition}

$B$ is a metric space (triangle inequality verified formally). It is the ray
$\mathbb{N}$ with a star of $2^i$ leaves attached at $\mathsf{hub}(i)$; balls
are finite, so $B$ is proper, and $\hpack(B,\mathsf{hub}\,0;\varepsilon)=\log 2$
for $\varepsilon\le 1$.

Let $T_2$ be the infinite rooted binary tree, $S=\{0,1\}^{*}$, with
$\sigma_2(R)=\{0,1\}^R$ and $d_S$ the tree metric via longest common prefix.
Then $\sigma_2$ is ULF with $K=2$ and has growth $\log 2$.

\begin{theorem}[Separation; Lean]\label{thm:sep}
For every lawful distortion $q=(D,K)$, at $\varepsilon=1$ and $c=1$,
\[
 \log 2 \in \Rates_{\{\sigma_2\},\,\mathrm{noExtra}}(1)
 \qquad\text{and}\qquad
 \log 2 \notin \Rates_{\{\sigma_2\},\,\mathrm{Relational}(q)}(1).
\]
In particular the two rate sets differ.
\end{theorem}

\begin{proof}[Proof sketch]
\emph{Block.} Send $\{0,1\}^R$ injectively onto the $2^R$ leaves of
$\mathsf{hub}(R)$. Distinct leaves are at distance $2\ge\varepsilon$, and all
lie in $\bar B(\mathsf{hub}\,0,R+1)$, so $r(R)=R+1$ works and $r(R)/R\to 1$.

\emph{Relational.} Suppose $\kappa$ satisfies $\mathrm{Relational}(q)$. Choose
$L$ with $D^{-1}\cdot 2(L+1)-K > 2$. For $u\ne v\in\{0,1\}^k$, the padded words
$u0^L, v0^L \in \{0,1\}^{k+L}$ satisfy $d_S \ge 2(L+1)$, so their images are at
host distance $>2$. In $B$, two points at distance $>2$ cannot share a hub's
star, so the $2^k$ padded images occupy $2^k$ distinct hubs. But the radial
budget confines them to $\bar B(\mathsf{hub}\,0,r(R))$, which meets only
$\lfloor r(R)\rfloor+1$ hubs. Since $r(R)/R\to 1$, this is $O(R)$, while
$2^k$ grows exponentially in $R$. Contradiction.
\end{proof}

The mechanism is that $B$ has exponentially many points but only linearly many
\emph{bounded-diameter shells}, whereas $T_2$ has exponentially many mutually
tree-distant vertices at each depth. The same count lifts from one source to
the natural family.

\begin{theorem}[Capacity-level separation over metric-ULF sources; Lean]\label{thm:sepcap}
Let $\mathfrak S$ be the family of metric-ULF sources. For every lawful
distortion $q$, every $\varepsilon>0$ and every $c$, no source in $\mathfrak S$
of positive growth is $\mathrm{Relational}(q)$-representable in $B$ at rate
$c$: $\Rates_{\mathfrak S,\mathrm{Relational}(q)}(c)\subseteq\{0\}$. At
$\varepsilon=c=1$ the block rate set contains $\log 2$ and the relational rate
set contains $0$, so as numbers
\[
  \Capy_{\mathfrak S,\mathrm{Relational}(q)}(1)=0
  \;<\;\log 2=\Capy_{\mathfrak S,\mathrm{noExtra}}(1).
\]
\end{theorem}

\begin{proof}[Proof sketch]
Two addresses in one star are at host distance $\le 2$, so the \emph{lower}
relational bound gives $d_S\le D(2+K)=:t_0$ for their histories, and a star
holds at most $f(t_0)$ histories of one census. The radial budget meets
$\lfloor r(R)\rfloor+1$ stars, so $|\sigma(R)|\le f(t_0)(r(R)+1)$, linear in
$R$; a source of growth $\beta>0$ has $|\sigma(R)|\ge e^{\beta R/2}$
eventually. The binary tree is metric-ULF with $f(t)=2^t$ (generation-$R$
vertices within tree distance $t$ share a prefix of length $R-t$), and
Theorem~\ref{thm:sep} supplies its block code; the one-history source
supplies $0$. The scalar form uses that $B$ is proper with
$\hpack(B;1)=\log 2$ (now formalized) through the block identity. Only the
lower side of the quasi-isometry sandwich is used.
\end{proof}

The balloon is the instance at scale $\varepsilon'\ge2$ of a general statement.

\begin{theorem}[Coarse packing converse; Lean]\label{thm:coarse}
Let $M$ be proper, $\sigma$ metric-ULF with ball bound $f$, and $\kappa$ a
code with Base at resolution $\varepsilon$ and $\mathrm{Relational}(D,K)$.
Then for every $\varepsilon'>0$ and every $R$,
$|\sigma(R)|\le f(\lceil D(2\varepsilon'+K)\rceil)\cdot
P(\bar B(o,r(R)),\varepsilon')$; hence, if $\sigma$ has growth $\beta$ and
is relationally representable at rate $c$ and the packing rate at scale
$\varepsilon'$ converges to $\hpack(\varepsilon')$, then
$\beta\le c\,\hpack(\varepsilon')$. Relational capacity over metric-ULF
sources is bounded by $c$ times the infimum of packing entropy over all
scales: the coarse growth rate, a quasi-isometry invariant.
\end{theorem}

\begin{proof}[Proof sketch]
A maximal $\varepsilon'$-separated subset of the budget ball is an
$\varepsilon'$-cover with exactly the packing number of points (Mathlib,
\texttt{isCover\_\allowbreak{}maximalSeparatedSet}, \texttt{encard\_\allowbreak{}maximalSeparatedSet}).
Histories assigned to the same cover point have addresses within
$2\varepsilon'$, hence source distance at most $D(2\varepsilon'+K)$ by the
lower bound, hence at most $f(\lceil D(2\varepsilon'+K)\rceil)$ per cell.
In $B$, at any $\varepsilon'\ge2$, a ball of radius $\rho$ packs at most
$\lfloor\rho\rfloor+1$ points, so $\hpack(B;\varepsilon')=0$ and
Theorem~\ref{thm:sepcap} follows (\texttt{balloon\_\allowbreak{}relational\_\allowbreak{}rate\_\allowbreak{}nonpos}).
\end{proof}

Block capacity reads packing entropy at the reader's scale; relational
capacity reads it at every scale. The gap can open only in hosts without
bounded geometry: if every $\varepsilon'$-ball packs at most $N_0$ points at
resolution $\varepsilon$, uniformly in the centre, the two packing rates have
the same limit (Lean, \texttt{packingRate\_\allowbreak{}scale\_\allowbreak{}invariant}). Scale-invariant
packing entropy is therefore necessary for zero relational tax over
metric-ULF sources; achievability (a quasi-isometric full-rate tree in the
host) is the open half, and neither Gromov hyperbolicity nor the absence of
conjugate points is necessary for it (a regular tree times a line carries the
binary tree at full rate; conjugate points are invisible to quasi-isometry).

\section{Two honest limitations}

\paragraph{(i) Representability versus capacity.}
Theorem~\ref{thm:sep} is stated over the singleton family $\{\sigma_2\}$, and
Theorem~\ref{thm:sepcap} lifts it to the metric-ULF family. It does \emph{not}
lift to the clock-ULF family. $B$ is itself a tree metric --- the leaves of a
common hub are at distance $2$, exactly their distance through the hub, so no
clique edges are present --- and the identity embedding of $B$'s own spanning
tree, whose census $\{\mathsf{leaf}(R,\cdot)\}$ is clock-ULF with $K=2$ but
not metric-ULF, is an isometry achieving growth $\log 2$. So
$\Capy_{\mathrm{rel}}(B)=\Capy_{\mathrm{block}}(B)=\log 2$ over the full
clock-ULF family, while $\Capy_{\mathrm{rel}}(B)=0<\log2$ over the metric-ULF
family: the separation is a statement about bounded valence.

\begin{question}\label{q:sep}
Is there a proper metric host with $\hpack>0$ such that \emph{no} clock-ULF
source of growth $c\,\hpack$ is relationally representable at rate $c$? The
balloon is not such a host. Equivalently, over sources of unbounded valence, is
a capacity-level separation attainable at all, or is some universality theorem
in force?
\end{question}

This is the question we would most like an expert opinion on, and we flag that
\cite{BLMN} proves a universality statement in a neighbouring regime (every
$n$-point metric space has a subset of size $n^{1-\epsilon}$ embedding in an
ultrametric at distortion $O(\log(2/\epsilon)/\epsilon)$). That theorem
concerns unbounded-degree ultrametrics on a fixed finite set; the balloon's
stars are ultrametric and are exactly what \cite{BLMN} would exploit, which is
why unbounded valence is the regime in which universality could still be in
force, and bounded valence (Theorem~\ref{thm:sepcap}) is where it is not.

\paragraph{(ii) The equality endpoint is imported.}
$\Capy_{\mathrm{rel}}(\Hyp^n_\kappa)=c(n-1)\sqrt{\kappa}$ rests on
\cite{Skenderi} and is not formalized. \cite{Tessera} and \cite{Kerr} give
positivity of relational capacity in broad homogeneous classes, not equality;
we state the corresponding homogeneity claims as conjectures, not theorems.

\section{Relation to neighbouring work}

Kolmogorov--Tikhomirov $\varepsilon$-capacity is the $\mathcal A=\mathrm{noExtra}$
case without a clock; the radial budget and the generative clock are what make
this a rate problem rather than a counting problem. Buyalo--Schroeder
\cite{BuyaloSchroeder} treat trees as coordinates and hosts as domains; we
reverse the variance. Successive refinement \cite{EquitzCover} is the
information-theoretic analogue of the persistence obligation, which we do not
compute here. \cite{DokuAmponsah} gives a rate--distortion AEP for
tree-indexed processes, with no host geometry.
